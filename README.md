# Student Portal Website

## Project Description

This is a simple Student Portal Website developed using HTML and CSS. It provides different pages for students to access academic information.

## Features

- Home Page
- About Page
- Student Registration
- Result Page
- Assignment Page
- Library Page
- Fee Details
- Notice Board
- Settings Page
- Contact Page

## Technologies Used

- HTML5
- CSS3
